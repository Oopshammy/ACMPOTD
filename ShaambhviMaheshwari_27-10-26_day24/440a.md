## problem link
https://codeforces.com/problemset/problem/440/A

## approach
traversing the episode watched array and if ep[n-2]==n-1, then printing n and IF ep[i]!=i+1, then printing (i+1).

## code
```python
n = int(input())

ep = list(map(int, input().split()))
ep.sort()

if ep[n-2]== n-1:
    print(n)
              
for i in range(n-1):
    if ep[i]==i+1:
        continue
    else:
        print(i+1)
        break
```
