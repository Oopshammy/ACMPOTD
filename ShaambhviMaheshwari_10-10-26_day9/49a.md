## problem link
https://codeforces.com/problemset/problem/49/A

## APPROACH
the approach i used here was creating the array that stored the sentence: each element either being a letter, a blank space or a question mark
then checking from the last and skipping through the blank or question mark elements till i reached the last or the first from last letter
then checking whether it is a vowel+y in small and caps or a consonant

## CODE
```python
sentence = list(input())
n = len(sentence)

vowel = ['a', 'e', 'i', 'o', 'u', 'y', 'A', 'E', 'I', 'O', 'U', 'Y']

for i in range(n):
    ch = sentence[n - i - 1]
    if ch == '?' or ch == ' ':
        continue

    is_vowel = False
    for j in range(12):
        if ch == vowel[j]:
            is_vowel = True
            break

    if is_vowel:
        print('YES')
        break
    else:
        print('NO')   
        break
```
