## problem link
https://codeforces.com/problemset/problem/41/A

## APPROACH
the approach i used here was creating 2 arrays, each for the input word then check their character is same or not by running a loop that check from start in word1 and from end in word 2.

## CODE
```python
word1=list(input())
word2=list(input())

if len(word1)!=len(word2):
  print("NO")
else:
  for i in range(len(word1)):
    if word1[i]!=word2[len(word1)-i-1]:
        print("NO")
        break
  else:
    print("YES")
```
