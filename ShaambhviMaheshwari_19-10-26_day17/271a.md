## problem link
https://codeforces.com/problemset/problem/271/A

## approach
taking the year as a string input then starting a for loop in the biggest range possible according to our constraints 
starting by increasing the year by 1 and storing it as an array
then starting another inner for loops to check for same digits. if same digits found then breaking from both k and j loop and if distinct digits then breaking fom all 3 loops.

## code
```python
given=int(input())

for i in range(8001):
    given=given+1
    gy = list(map(int, str(given)))
    found_duplicate = False
    for j in range(4):
        for k in range(j+1,4):
            if gy[j]==gy[k]:
                found_duplicate=True
                break  
        if found_duplicate:
            break       
    if not found_duplicate: 
     break

print(given)
```
