## problem link
https://codeforces.com/problemset/problem/158/A

## approach
first check whether the score at M'th position is positive or not
is it is notpositive then checking all the previous scores and reducing the count from m
if it is positive then checking whther there are same scores after it and increasing the count from m

## code
```python
n,m = map(int, input().split())
scores = list(map(int, input().split()))

count=0
count = m

if scores[m-1]<=0:
 for i in range(m):
    if scores[i]<=0:
        count-=1
else:
   for i in range(m,n):
      if scores[i]== scores[m-1]:
         count+=1

print(count)
```
