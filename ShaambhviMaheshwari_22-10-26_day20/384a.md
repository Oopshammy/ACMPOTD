## problem link
https://codeforces.com/problemset/problem/384/A

## approach
initializinf a 2d array
and for even rows even columns are C to maximize the count of coders

## code
```python
n = int(input())

rows = n
cols = n
chess= [[0 for _ in range(cols)] for _ in range(rows)]
cnt=0
for i in range(n):
    if i%2==0:
        for j in range(n):
          if j%2==0:
            chess[i][j]='C'
            cnt=cnt+1
          else:
            chess[i][j]='.'   
    else:
       for j in range(n):
          if j%2==0:
             chess[i][j]='.'
          else:
             chess[i][j]='C'
             cnt=cnt+1

print(cnt)                    
for row in chess:
   print("".join(row))
```
