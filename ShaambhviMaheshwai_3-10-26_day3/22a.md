## APPROACH
the approach i used here was very simple, first input the user input into an array using list and split function to have various elements.
then use theset function to only keep the unique elements and then the sort function to keep then in increasing order.

## CODE
```python
n= int(input())

array = list(map(int, input().split()))

arr = list(set(array))

arr.sort()

print(arr[1] if len(arr)>1 else 'NO')
```
