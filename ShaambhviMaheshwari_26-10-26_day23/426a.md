## problem link
https://codeforces.com/problemset/problem/426/A

## approach
taking the input array for mug volume and sorting it and adding the volume upto n-1 mugs. if mug total volume more than cup volume then printing NO else YES

## code
```python
n , cupvol = map(int, input().split())


mugvol= list(map(int, input().split()))
mugvol.sort()
volume = 0

for i in range(n-1):
    volume = volume+mugvol[i]

if volume>cupvol:
    print('NO')
else:
    print('YES')
```
