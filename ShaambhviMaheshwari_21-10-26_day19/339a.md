## problem limk
https://codeforces.com/problemset/problem/339/A

## approach
making an array of the numbers given in the question. sorting it and appending it to the question 

## code
```python
sum = list(input())

n = int(len(sum)/2) + 1
num=[0]*n

for i in range(n):
    num[i]=sum[2*i]
    
num.sort()

for i in range(n):
    sum[2*i]=num[i]
  

print("".join(sum))
```
