## problem link
https://codeforces.com/problemset/problem/228/A

## approach
running a loop of n in range (4) and an inner loop of m in the range(n+1,4) 
checking if n=m then count+=1 and appending the m'th index to 0
and simultaneously checking if the n'th index is 0 then breaking and checking further

## code
```python
shoes = list(map(int, input().split()))

count=0

for n in range(4):
    for m in range(n+1,4):
     if shoes[n]==0:
        break
     elif shoes[n] == shoes[m]:
        count+=1
        shoes[m]=0

print(count)
```
