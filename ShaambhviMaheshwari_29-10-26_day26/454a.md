## problem link
https://codeforces.com/problemset/problem/454/A

## approach
first double loop
running i'th loop till (n-1)//2 [half of the matrix rows excluding the middle row]
<br>
running the j'th loop from ((n-1)//2)-i till ((n-1)//2)+i+1  to secure the elemenet from middle to right and left<br>
0th row needs 0 element to right and left of the middle element <br>
1st row needs 1 element to right and left to the middle element and so on...

then second loop secures all the element of the middle most row

then printing the matrix without spaces between the elements [sep=""]

## code
```python
n = int(input())

matrix = [["*" for _ in range(n)] for _ in range(n)]

for i in range((n-1)//2):
    for j in range(((n-1)//2)-i, ((n-1)//2)+i+1):
        matrix[i][j]="D"
        matrix[n-i-1][j]="D"


for i in range(n):
    matrix[(n-1)//2][i]="D"

for row in matrix:
    print(*row, sep="")
```
