https://codeforces.com/problemset/problem/443/A

## approach
the first problem we faced was that while inputting: the first and last elements were inputted along with the curly brackets and the rest were inputted along with ","
to solve it we first removed curly bracket which all the inputs had.
then the second problem we faced was during empty string. if we removed the curly and splitted the string on "," together then the series became an empty string of the form [""] which was making our count 1 instead we needed series to be []
HENCE WE:
first stripped the input of curly bracket and then checked whther the string is empty or not, if yes then made series an empty string
if not then stripped the string of "," also. then checked whether the letter is already in our check string, if not then appended it and increased count by 1

## code
```python
user_input=input()

curly_removed = user_input.strip("{}")

if curly_removed == "":
     series=[]
else:
     series=[item.strip() for item in curly_removed.split(",")]

n = len(series)
check=[n]
count=0

for i in range(n):
    if series[i] in check:
         continue
    else:
         check.append(series[i])
         count=count+1

print(count)
```
