## problem link
https://codeforces.com/problemset/problem/50/A

## approach
comparing whether n is greater or m supposing m are rows and n are columns of a mXn matrix.
if smaller is odd then making x-1(even) square and filling with tiles then filling the rows ad columns accordingly. 

## code
```python
n, m = map(int, input().split())

count=0
if m>n:
    if n%2==1:
     count= m*(n-1)/2
     if m%2==1:
        count = count + (m-1)/2
     else:
        count = count + m/2   
    else:
       count= m*n/2
else:
   if m%2==1:
     count= n*(m-1)/2
     if n%2==1:
        count = count + (n-1)/2
     else:
        count = count + n/2  
   else:
      count= n*m/2       

print(int(count))      
  

```
