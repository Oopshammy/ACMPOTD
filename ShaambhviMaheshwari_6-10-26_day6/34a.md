https://codeforces.com/problemset/problem/34/A
## APPROACH
the approach i used here was creating an array for soldier height then creating an array for the difference of neighbouring soldier's heights
then selecting the minimum vaue from the difference array and printing the corresponding soldier position.

## CODE
```python
n= int(input())

height=list(map(int,input().split()))

diff=[]

for i in range(n):
    if i !=n-1:
     diff.append(abs(height[i] - height[(i + 1)]))
    else:
       diff.append(abs(height[n-1] - height[0])) 

min_diff= diff.index(min(diff))

if min_diff == n-1:
   print(n,1)
else:
   print(min_diff+1,min_diff+2)   

```
