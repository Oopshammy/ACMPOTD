## problem link
https://codeforces.com/problemset/problem/214/A

## approach
the approach was simple
starting loop for A in range 35 then an inner loop for B in the range 35 (since 35^2>1000)
then increasing countby 1 everytime it satisfied the equations

## code
```python
n,m = map(int, input().split())

count = 0

for a in range(35):
    for b in range(35):
        if a**2 + b == n and a + b**2 == m:
            count+=1

print(count)
```
