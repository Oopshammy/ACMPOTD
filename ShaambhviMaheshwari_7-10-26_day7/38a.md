## APPROACH
the approach i used here was creating an array for years and then adding the years corresponding to the ranks by putting first input as start and second as finish and running an add loop on years for 
in the range(start-1, finish-1)

## CODE
```python
n=int(input())

years=list(map(int,input().split()))

ranks=list(map(int,input().split()))

start=ranks[0]
finish=ranks[1]
count=0

for i in range(start-1, finish-1):
  count+=years[i]
print(count)
```
