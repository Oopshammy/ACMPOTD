## problem link
https://codeforces.com/problemset/problem/386/A

## approach
traversing the array to find the largest bidder and the second largest bid by:
if bid greater then the biggest bidder's bid, then replacing second highest bid with the previous highest bid and replacing previous highest bidder with current highest
if bid greater than second highest bid but small than highest bid then only replacing the second highest bid value.

## code
```python
n = int(input())

bid=list(map(int, input().split()))

first_pos=0
second=0

for i in range(1,n):
    if bid[i]>bid[first_pos]:
        second=bid[first_pos]
        first_pos=i
    elif bid[i]>second:
        second=bid[i]
       
print(first_pos+1, second)
```
