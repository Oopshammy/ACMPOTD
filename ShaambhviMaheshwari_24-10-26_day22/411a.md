## problem link
https://codeforces.com/problemset/problem/411/A

## approach
inputing the password and checker whther it has upper, lower digit and minimum 5 characters
and printing correct if all conditions True

## code
```python
psw=list(input())
length=len(psw)
lc= False

if length>=5:
    lc= True


small = False
cap = False
dig = False

for char in psw:
    if char.isupper(): 
        cap = True
    if char.islower(): 
        small = True
    if char.isdigit(): 
        dig = True


if lc and dig and small and cap:
    print("Correct")
else:
    print("Too weak")
```
