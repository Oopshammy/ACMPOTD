## Problem link
https://codeforces.com/problemset/problem/32/A

## approach
first i took the user input, created an array for the second user input for the height of soldiers. then the algo that i ran 
consisted of 2 embedded loops, first it checked whether 2 different soldiers were picked to check their height diff (j != i)
then there were 2 cases 
1: arr[j]>arr[i]
2: arr[i]>=arr[j]
to check their height difference was considered to make a set or no.

##code
```python
n,d = map(int, input().split())

arr = list(map(int, input().split()))

count = 0

for i in range(n):
    for j in range(n):
        if j != i:
            if arr[j] > arr[i]:
                if arr[j] - arr[i] <= d:
                    count+=1
            else:
                if arr[i] - arr[j] <= d:
                    count+=1

print(count)
```
