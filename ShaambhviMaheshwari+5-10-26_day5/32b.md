## Problem link
https://codeforces.com/problemset/problem/32/B

##code
```python
s = input()

i = 0
ans = ""

while i < len(s):
    if s[i] == '.':
        ans += '0'
        i += 1
    else:
        if s[i + 1] == '.':
            ans += '1'
        else:
            ans += '2'
        i += 2

print(ans)
```
